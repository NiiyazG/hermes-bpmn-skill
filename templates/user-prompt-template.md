# Шаблон запроса к Hermes

Создай BPMN 2.0 диаграмму для следующего бизнес-процесса: <описание>.

Требования:
1. Сначала извлеки известные факты и задай только критически необходимые наводящие вопросы.
2. Не придумывай владельцев и маршруты `Нет`, если они не определены.
3. Раздели внутренние роли на Lanes, внешних участников на Pools.
4. Проверь BPMN-семантику и геометрию стрелок.
5. Выдай полный пакет: BPMN, XML, SVG, PDF, PNG, JPG, WEBP, TIFF, EPS (если доступен Inkscape), HTML, JSON-модель, краткое описание, validation report и ZIP.
6. Дай в ответе очень краткое описание процесса на 3–6 предложений.
7. Не выдавай финальную версию, если validation report не PASS; сначала исправь ошибки.
