# BPMN 2.0 — рабочие правила навыка

## Pool / Lane
- Pool = независимый participant.
- Lane = роль/подразделение внутри participant.
- Task принадлежит ровно одному Lane.
- Task не пересекает границу Lane.

## Sequence Flow
- Только внутри одного Pool.
- Сплошная линия.
- Не соединяется с Data Object.

## Message Flow
- Только между разными Pools.
- Не используется между внутренними подразделениями одной организации.

## Tasks
- Имя: глагол + объект.
- User Task — человеческая работа.
- Service Task — автоматизированная работа.
- Manual Task — ручная физическая работа, если она действительно ручная.

## Events
- Start Event не имеет входящего Sequence Flow.
- End Event не имеет исходящего Sequence Flow.

## Gateways
- XOR — взаимоисключающие ветки.
- AND — реальный параллелизм.
- Gateway не выполняет работу.
- Gateway-вопрос должен быть коротким.
- Условие размещай на outgoing flow.

## Data
- Data Object / Data Store — данные, не работа.
- Связывай через Data Association.

## Согласования
Не объединяй два согласования, если они проверяют разные артефакты/стадии.

## Тестирование
Не объединяй внутреннее, приемочное и пользовательское тестирование, если различаются владелец, критерии или маршрут `Нет`.
