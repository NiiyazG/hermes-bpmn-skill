# Стандарт начертания стрелок

## Sequence Flow
- сплошная линия;
- один наконечник только у цели;
- горизонтальные/вертикальные сегменты;
- повороты 90°;
- никаких диагоналей;
- никаких двунаправленных линий.

## Заход в блок
- последний waypoint находится на внешней границе target;
- последний сегмент перпендикулярен стороне target;
- вершина наконечника не должна заходить внутрь Task;
- текст и иконка не перекрываются наконечником.

## Выход из блока
- первый waypoint на внешней границе source;
- линия не должна визуально начинаться внутри Task.

## Несколько входов
- разные точки подключения;
- при необходимости разные стороны;
- нельзя накладывать наконечники друг на друга.

## Возвраты
- вести по свободному коридору;
- не использовать Lane border как маршрут;
- возвращать в конкретный Task/Gateway;
- локальный цикл предпочтительнее длинной общей магистрали.

## Подписи
- `Да/Нет` возле начала соответствующей outgoing ветки;
- не на incoming;
- не посередине длинной петли.

## Проверка
Если при масштабе 25–50% нельзя однозначно понять, куда идет стрелка, маршрут нужно переразвести.
